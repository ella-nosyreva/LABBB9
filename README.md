# Лабораторная работа 9 (Вариант 10)

## Условие задачи
Написать программу, выводящую на экран заданную геометрическую фигуру, нарисованную с помощью заданного с клавиатуры символа. Предусмотреть возможность изменения размеров фигуры путем задания ее размеров в количестве символов пользователем. 
Фигура: Правильный четырехугольник (ромб), условие заполнения: да (закрашен), символ: `$`.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Объявить переменные: `size` (размер ромба), `repeat` (для повтора программы), `symbol` (символ для рисования).
3. Запустить цикл `do-while` (для повторения программы по желанию пользователя).
4. Запросить у пользователя символ для рисования.
5. Запросить у пользователя размер ромба (целое число > 0).
6. Проверить, что размер больше 0. Если нет — вывести ошибку.
7. Если размер корректен, запустить внешний цикл `for` для верхней половины ромба (от 0 до `size-1`):
   - Внутренний цикл для печати пробелов (для отступа).
   - Внутренний цикл для печати символов (закрашенная часть).
   - Переход на новую строку.
8. Запустить внешний цикл `for` для нижней половины ромба (от `size-2` до 0):
   - Внутренний цикл для печати пробелов.
   - Внутренний цикл для печати символов.
   - Переход на новую строку.
9. Спросить, продолжать ли программу. Если да — вернуться к шагу 4.
10. **Конец**
